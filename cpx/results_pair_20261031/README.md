## 实际设置和启动入口

| 设置 | 8B | 2B |
|---|---|---|
| 逐题调用预算 | min(30,int(20*complexity)) | min(20,int(10*complexity)) |
| 模型服务 | MAI-UI-8B / GPU5 / 18197 | MAI-UI-2B / GPU2 / 8100 |
| 服务精度、上下文、图片数 | BF16 / 24576 / 3 | BF16 / 24576 / 3 |
| 服务最大并发 | 8（本实验两路） | 2 |
| CPU offload | 0 GiB | 0 GiB（启动参数未指定，vLLM默认0） |
| AndroidWorld | 每组独立1容器 | 每组独立1容器 |
| 顺序、seed | 学长e2e116n题序，seed30 | 相同 |
| FULL45图 | 独立空图初始化，116题间顺序在线积累 | 相同，和8B图完全独立 |
| FULL45探索 | 窗口30秒，最多3探针 | 相同 |
| BASE | 无图执行、无探索 | 相同 |

普通FULL45基于 upstream `81a1531758da249c2acb74baa761d2da65e01b1c`，未启用SEENR热启动和旧CPX recovery_guard。图为空，但学长服务器取得的词频/IDF统计先验仍加载。MAI官方提示词、原生动作历史与最后三图适配配置固定。仅保留恢复重问不越调用预算的算法补丁；宿主机监督、MAI适配器和启动封装另见源码包。

- 8B启动脚本和完整部署源包：[puregpu_run_20261030](../puregpu_run_20261030/)。
- 2B启动脚本和完整部署源包：[mai2b_run_20261030](../mai2b_run_20261030/)。
- **实际部署时的完整参数、服务命令行、镜像ID、题序和源码哈希**：[8B run_config](summary/8B/run_config.json)、[2B run_config](summary/2B/run_config.json)。
- 日志打包时从服务器再次读取的启动脚本：[source_review/8B](source_review/8B/)、[source_review/2B](source_review/2B/)。
- nohup宿主监督支持异常任务留档后切下一题、设备重启；连续3题基础设施失败会停止该组，避免无限重启。两轮均完成116题。
- 2B启动前曾因就绪脚本配置名漏改而失败，修正后又遇无障碍服务启动未就绪；这些都发生在首题执行前，已保留infra日志与配置更正说明，不作为已完成任务。8B本轮设备无重启。2B的启动恢复次数不能解释为实验中途任务崩溃数。
